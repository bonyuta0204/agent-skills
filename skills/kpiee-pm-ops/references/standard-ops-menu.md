# Standard Ops Menu

PMが日常運用で繰り返し実行する庶務メニュー。  
各メニューは「開始条件」「最小成果物」「完了条件」を必ず満たす。

## 1) Issue Intake

- 開始条件: 新規要件、障害報告、仕様変更依頼を受領した
- 最小成果物:
  - 背景
  - 目的
  - 完了条件
  - 非対象（やらないこと）
- 完了条件:
  - 優先度が設定されている
  - 依存タスクが明記されている
  - 担当候補が設定されている

## 2) Issue Triage

- 開始条件: 未整理Issueがある
- 最小成果物:
  - 分類（バグ/機能/調査/運用）
  - 影響度（高/中/低）
  - 緊急度（高/中/低）
  - 初動担当
- 完了条件:
  - ラベルが排他的に整理されている
  - マイルストーンが設定されている

## 3) PR Readiness

- 開始条件: 実装ブランチがpushされた
- 最小成果物:
  - PRタイトル
  - PR本文
  - 関連Issueリンク
  - チェック項目
- 完了条件:
  - テンプレート必須項目が埋まっている
  - milestoneが設定されている
  - base/headが意図どおり

## 4) CI Operations

- 開始条件: PRにcheckがぶら下がった
- 最小成果物:
  - check結果の分類（pass/fail/waiting）
  - 失敗時の一次原因
  - 次アクション（修正/再実行/承認待ち）
- 完了条件:
  - 必須checkが完了している
  - 失敗件数が0、または許容理由が明文化されている

## 5) Deployment Operations

- 開始条件: リリース判断がGo
- 最小成果物:
  - デプロイ対象
  - 実行手順
  - ロールバック条件
  - 実行ログ要約
- 完了条件:
  - デプロイ結果が記録されている
  - 監視ポイントが設定されている
  - 異常時の連絡先と次手順が明文化されている

## 6) Daily Reporting

- 開始条件: 日次締め、または状態変化が発生した
- 最小成果物:
  - 今日の進捗
  - 未解決リスク
  - 明日の実行計画
- 完了条件:
  - ステークホルダーに共有可能な形で出力されている

## 7) Release Summary

- 開始条件: リリース直前または直後
- 最小成果物:
  - 含める変更一覧
  - 既知の制約
  - フォローアップ計画
- 完了条件:
  - Go/No-Goの根拠が明示されている
  - 未解決項目の責任者が明確になっている
